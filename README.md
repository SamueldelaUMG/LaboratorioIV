Este repositorio contiene los ejercicios de preparación para el primer examen parcial de Programación Orientada a Objetos en Java.

## Temas

- Clases y objetos
- Herencia
- Polimorfismo
- Encapsulamiento
- Clases abstractas
- Manejo de excepciones
- Arreglos
- Diagramas UML
- Diagramas de secuencia
- Pseudocódigo
